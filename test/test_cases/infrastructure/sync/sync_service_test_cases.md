## 実行環境について

- **SQLite**: `sqflite_common_ffi` を使い、実際の SQLite エンジンをテスト専用の一時ディレクトリで使用する
  （`FolderLocalDataSource` / `WordLocalDataSource` / `FlashcardResultLocalDataSource` /
  `SettingsLocalDataSource` / `SyncQueueDataSource` / `SyncLocalDataSource` / `DatabaseHelper` は実クラス）。
- **リモート**: `SyncRemoteDataSource` を実装した手書きフェイク `FakeSyncRemoteDataSource`
  （このファイル内に定義。インメモリで `fetchChanges` / `writeIfNewer` を再現し、呼び出し順・
  ゲート（`Completer`）による一時停止・1回だけの例外を差し込める）。
- **ネットワーク接続**: `test/helpers/fake_infrastructure.dart` の `FakeConnectivityMonitor`。
- **観測**: `FolderRepositoryImpl` 等の取得メソッド、`SyncLocalDataSource.find`、`SyncQueueDataSource`、
  `SyncLocalDataSource.readMeta`（取得の基準）、`FakeSyncRemoteDataSource.calls`（呼び出し順）。
