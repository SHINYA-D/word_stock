## 実行環境について

SampleViewModel はサブクラスでの状態 override を行わず、`sampleRepositoryProvider` を
`test/helpers/fake_infrastructure.dart` の `FakeSampleRepository`（失敗キュー・`Completer`のゲート・
呼び出し記録を持つ手書きフェイク）に差し替え、本物の `SampleViewModel` をそのまま動かして検証する。
BottomNav・`/folder/:folderId`・`/login` への画面遷移を確認するテスト（SMP-D02, SMP-T01, SMP-E04）は、
アプリ本体の `router.dart` には依存せず、`ShellPage` を含む最小限のテスト専用 `GoRouter` を用いる
（`test/presentation/shell/shell_page_test.dart` と同じ方針）。
4章（ViewModel の状態）は `test/presentation/sample/sample_view_model_test.dart`（別ファイル）の担当のため、
本ファイルでは画面で観測できる結果（表示・ダイアログ・スナックバー・遷移）のみを確認する。
