# サンプル画面 概要設計書

## 画面構成

- AppBar には「サンプル」と表示する。
- ボトムナビゲーションバーを表示し、「テスト」タブが選択されている状態にする。
- 右下に FloatingActionButton（アイテム作成ボタン）を配置する。add がわかるアイコンにする。
- 一覧の各アイテム（フォルダ）の右端に `Icons.more_vert` を配置する。

## 初期表示

初期表示は2パターンある。

1. この画面を開いたとき、アイテムがなければ、サンプルのアイコンを表示し、その下に「サンプルがありません」という文言を表示し、その下に add がわかるアイコンと「サンプルを作成」という文言を持つボタンを表示する。
2. この画面を開いたとき、アイテムが存在していれば、そのアイテムを List 形式で表示する。アイテムが多ければ、下までスクロールできる形式にする。

一覧は作成順（古いものが上）に並べる。

一覧を下に引っ張って離す（プルして更新）と、一覧を読み込み直す。

## 各ボタンの処理内容

| ボタン | 押下したときの処理 |
|-------|------------------|
| FloatingActionButton（アイテム作成ボタン） | 作成ダイアログを表示する。アイテム（Folder）を作成することができる |
| 「サンプルを作成」（アイテムがないときのボタン） | 作成ダイアログを表示する。処理内容は FloatingActionButton と同じ |
| アイテムの `Icons.more_vert` | 「削除」「編集」ボタンを表示する |
| 「削除」 | 削除ダイアログを表示する |
| 「編集」 | 編集ダイアログを表示する |

## ダイアログ

### 作成ダイアログ

上から次の順で配置する。キャンセルボタンと作成ボタンは Row で並列にする。

1. タイトル「サンプルを作成」
2. 入力項目タイトル「サンプル名」
3. 入力欄
4. 注意書「半角20文字（全角10文字）まで」
5. キャンセルボタン、作成ボタン

| 操作 | 処理 |
|-----|------|
| キャンセルを押下 | ダイアログを閉じて、サンプル画面に戻る |
| 作成を押下 | 入力欄に記載したアイテム（フォルダ）を作成して、サンプル画面に戻り、そのフォルダを表示する |
| 入力欄が空欄 | 作成は押せないように制御する。空白（半角・全角スペース）だけの場合も空欄と同じ扱いにする |
| 既存のアイテムと同じ名前を入力 | 作成できる（同じ名前を許す） |
| 入力できる長さ | 幅20まで入力できる（半角文字は1、全角文字〈かな・カナ・漢字・全角英数記号・全角スペース〉は2として数える）。幅20を超える文字を入力しようとしても、その入力は反映せず、入力欄は入力前のままにする。絵文字など、半角・全角のどちらにも当たらない文字の幅は定めない |
| 前後の空白 | 作成するときは、入力の前後の半角・全角スペースを除いた名前にする。途中のスペースは残す。幅20の判定は、空白を除く前の入力で行う |
| 作成の処理中 | 作成は押せないようにする。それ以外の処理中の表示（ローディング表示など）は出さない |
| 作成が失敗したとき | ダイアログを閉じず、入力した内容を残す（失敗の伝え方は「操作が失敗したとき」） |

### 削除ダイアログ

上から次の順で配置する。キャンセルボタンと削除ボタンは Row で並列にする。

1. タイトル「サンプルを削除」
2. 注記「※「アイテム名」を削除しますか？」
3. キャンセルボタン、削除ボタン

| 操作 | 処理 |
|-----|------|
| キャンセルを押下 | ダイアログを閉じて、サンプル画面に戻る |
| 削除を押下 | ダイアログを閉じて、対象のファイルを削除する |

### 編集ダイアログ
作成ダイアログと同じ構成にする。ただし、タイトルは「サンプルを編集」、作成ボタンは「保存」ボタンにし、入力欄の初期値は既存のアイテム名にする。
入力欄の制約（空欄・空白だけのときは押せない、同じ名前を許す、入力できる長さ、前後の空白）と、処理中・失敗したときの扱いは作成ダイアログと同じ。

| 操作 | 処理 |
|-----|------|
| キャンセルを押下 | ダイアログを閉じる。アイテム名は変更しない |
| 保存を押下 | アイテム名を編集後の名前に変更して、ダイアログを閉じる |

## 操作が失敗したとき

作成・編集・削除・プルして更新が失敗したときは、失敗の種類（通信エラー・認証エラーを含む）に関わらず、スナックバーで「操作が失敗しました。」と表示する。一覧はそのまま表示し、エラー画面は表示しない。作成・編集が失敗したときは、ダイアログを閉じずに入力を残す。

一覧の初期読み込み（エラー画面の「再試行」を含む）が失敗したときだけ、エラー画面を表示する。エラー画面には「サンプルの読み込みに失敗しました」と「再試行」ボタンを表示する。ただし通信エラー・認証エラーのときは、エラー画面ではなく通信エラーダイアログを表示し、ログアウトしてログイン画面に戻る。

## 画面遷移

| 操作 | 遷移先 |
|-----|-------|
| サンプル画面に表示されているアイテムをタップ | word画面（単語一覧画面 `FolderRoute`）。HomePage と同じく `folderId` にアイテムの id、`$extra` にアイテムの名前を渡す |
