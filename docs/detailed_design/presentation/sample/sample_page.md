# サンプル画面 振る舞い仕様書

## 1. 機能概要

テスト専用の画面。サンプル（アイテム）の一覧を表示し、作成・名前の編集・削除と、単語一覧画面への遷移ができる。
ボトムナビ「テスト」タブ（`/sample`）から開く。

## 2. データ定義

### 2.1 Sample

| 項目 | 型 | 説明 |
|------|----|------|
| id | String | サンプルの ID |
| name | String | サンプル名 |
| createdAt | DateTime | 作成日時。一覧の並び順（古いものが上）に使う |
| updatedAt | DateTime | 最終更新日時 |

## 7. 対象外

- 作成の `NotFoundFailure`: 作成は既存のサンプルを対象にしない操作のため発生しない
- 「サンプルを作成」ボタン（0件表示）から開いた作成ダイアログの、処理中の無効化・処理中表示・二重操作・処理中のキャンセル／外側タップ／戻る・外側タップ・戻る・前後の空白の除去・入力の境界・最大幅の表示・`NetworkFailure`・`AuthFailure`: FloatingActionButton から開くものと同じ作成ダイアログで、ダイアログ内の動作は起動元で変わらないため、FloatingActionButton から開いた場合の ID（SMP-C06〜C18、SMP-C21、SMP-E14、SMP-E15、SMP-N01、SMP-N02）で扱う。起動元で画面の見え方が変わる表示・成功・キャンセル・失敗だけを SMP-C02、SMP-C04、SMP-C19、SMP-C20 に書いた
- 作成の「同じ値」を 0件表示から行う場合: 既存のサンプルがないため該当しない
- メニューの表示（`Icons.more_vert`）とアイテムのタップ（画面遷移）の Failure 4種類: Repository を呼ばない操作のため発生しない
- アイテムの二重タップ（遷移先が2回開く等）: 原則-4 はデータを変更する操作が対象で、遷移はデータを変更しない。概要設計書にも定めがないため扱わない
- プルして更新の二重操作: 読み取りだけの操作で、二重に実行されてもデータは変わらないため扱わない
- 再試行の二重操作（完了前に2回続けて操作しても読み込みは1回だけ）: 読み取りだけの操作で、二重に実行されてもデータは変わらないため扱わない（原則-4 はデータを変更する操作の二重送信が対象）。なお、読み込み中は「再試行」ボタン自体が表示されない（SMP-D16）
- `ErrorScreen` 表示中のプルして更新: 概要 §初期表示のプルして更新は一覧に対する操作で、`ErrorScreen` は一覧の代わりに表示され一覧を持たない。`ErrorScreen` 表示中の読み込み直しは「再試行」（SMP-D15〜D17、SMP-E06〜E10）で扱う
- 遷移先（単語一覧画面）の表示内容: 遷移先の画面の仕様書で扱う
- 概要 §画面遷移の「HomePage と同じく」: HomePage には承認済みの仕様書がないため、概要設計書に明記された `folderId`（アイテムの id）と `$extra`（アイテムの名前）以外は HomePage に合わせない
- ログインしていない状態でこの画面を開く場合: ルーターがログイン画面へ移動させるため、この画面は表示されない（要件 §ルーティング）
- `NetworkErrorDialog`・`ErrorScreen` の部品そのものの文言・閉じ方: 全画面共通の部品（`core/widgets/`）の仕様で、この画面の仕様書では扱わない（この画面から渡す文言「サンプルの読み込みに失敗しました」だけを書いた）
- 幅の数え方で半角・全角のどちらにも当たらない文字（絵文字・結合文字など）: 概要設計書は「半角20文字（全角10文字）」だけを定めており、それ以外の文字の数え方は決まっていないため扱わない
- `MockSampleRepository` の初期データ（`mock-user-id` の「サンプルA」「サンプルB」）と応答の待ち時間: テスト用のデータ・待ち時間で、振る舞いの仕様ではない
- オフライン同期（`sync_queue`・競合解決）: `online_offline.md` に本機能の記載がないため扱わない
- 削除の「同じ値」「入力の境界」: 削除は名前を入力しない操作のため該当しない
